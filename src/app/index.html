HOW TO PLAY

Six registers per finger shape:
Index finger = sub-bass
+ Middle finger = bass
+ Ring finger = low-midrange
+ Little finger = midrange
+ Thumb (open hand) = high-midrange
Index + Little finger = treble
Tilt slowly to glide within each register.

Major/minor chords in A major
the right hand selects the degree using the number of fingers
(1 finger = I, 2 = ii, 3 = iii, 4 = IV, 5 = V)
Keep the left hand open and tilt it to control the timbre (filter). The note continues to sound as long as the right hand indicates a degree.
